## 一、项目基础

1. 创建名为 BBB 的 Xcode 项目，Target 名称为 BBB，Bundle ID 为 `v.babybuddy`，手动签名（Team: `73AUQDMCJ2`，Profile: `bbb`）
2. 添加 Widget Extension Target：`BaByBuddyWidgetExtension`，Bundle ID 为 `v.babybuddy.FeedingWidget`
3. 主 App Target 使用 `fileSystemSynchronizedGroups = BBB` 管理源文件
4. Widget Extension Target 使用 `fileSystemSynchronizedGroups = BaByBuddyWidget` 管理源文件
5. 主 App 的 Entitlements 文件存储在 `BBB/BBB.entitlements`，包含 `com.apple.security.application-groups: group.v.babybuddy`
6. Widget Extension 的 Entitlements 文件存储在 `BaByBuddyWidgetExtension.entitlements`，包含 `com.apple.security.application-groups: group.v.babybuddy`
7. 主 App 的 Info.plist 文件存储在 `BBB/Info.plist`，包含 `NSSupportsLiveActivities: true`
8. 设置 App Group 共享容器 ID 为 `group.v.babybuddy`，主 App 和 Widget Extension 之间通过 App Group 的 UserDefaults 共享数据
9. 部署目标为 iOS 17.0
10. 项目根目录包含 `BBB/` 目录（主 App 源代码）和 `BaByBuddyWidget/` 目录（Widget 源代码）

## 五、交互动作

28. 交互动作定义在 `BabyAction` 枚举中，包含：
    - idle（待机）
    - shake（摇一摇，持续 2.5s）
    - pet（抚摸，持续 2.0s）
    - poke（戳，持续 1.5s）
    - listen（听，持续 3.0s）
    - nursing（记录喂养，持续 1.8s）
    - diaper（记录尿布，持续 1.8s）
    - breastfeed（记录吸乳，持续 1.8s）
    - sleep（记录睡眠，持续 1.8s）
29. 每个动作有对应的标题（中文）、emojiIcon、systemImage
30. 动作分为两类：基础互动（`isBasicInteraction`: shake, pet, poke, listen）和记录型动作（`isRecordable`: nursing, diaper, breastfeed, sleep）
31. 摇一摇检测通过 `ShakeDetector`（`UIViewControllerRepresentable`）实现，监听 `motionEnded` 事件
32. 抚摸手势通过 `DragGesture(minimumDistance: 0)` 的 `onChanged` / `onEnded` 实现，触发后 0.6 秒无操作自动结束
33. 点击空白区域触发 poke 动作
34. 点击语音 mic 按钮触发 listen 动作
35. 动作触发后自动在指定持续时间内恢复到 idle 状态，使用 `DispatchQueue.main.asyncAfter`

## 十六、Live Activity 数据模型

109. 创建 `FeedingActivityAttributes` 符合 `ActivityAttributes` 协议，包含：

110. 创建 `FeedingIntervalStatus` 枚举，6 个状态等级：justFed(0), tooSoon(1), safe(2), maybeHungry(3), definitelyHungry(4), warning(5)
111. `FeedingIntervalStatus` 提供基于距上次喂养时间和宝宝月龄的初始化器
112. 根据宝宝月龄分为 4 个阶段的喂养间隔阈值：
    - 新生宝宝（<1月）：justFed<0.75h, tooSoon<1.25h, safe<2h, maybeHungry<3h, definitelyHungry<4h
    - 1-3月：justFed<1h, tooSoon<2h, safe<3h, maybeHungry<4h, definitelyHungry<5h
    - 3-6月：justFed<1.5h, tooSoon<2.5h, safe<4h, maybeHungry<5h, definitelyHungry<6h
    - 6月+：justFed<2h, tooSoon<3h, safe<5h, maybeHungry<6.5h, definitelyHungry<8h
    - 未知月龄：默认使用 3-6 月阈值
113. `FeedingIntervalStatus` 提供 extension 属性：`label`（中文描述）、`emoji`、`backgroundColorHex`、`accentColorHex`
114. `FeedingActivityAttributes` 和 `FeedingIntervalStatus` 在主 App 和 Widget Extension 中各有一份完全相同的定义
