## 新首页实验方案：小动物直播岛

- 用户明确要求：不要直接修改当前首页；先在 message/每日消息页落地新首页方案，后续确认后再替换首页。
- 目标效果参考 Pokemon Sleep 的“大地图局部视窗 + 可拖动探索 + 小动物自由移动”，但视觉语言不要照抄 Pokemon Sleep。
- 新首页应模拟抖音/TikTok 直播间，而非真实直播功能：
  - 背景是接近正方形的大地图，手机屏幕只显示其中一部分。
  - 中间区域放小木屋作为场景核心。
  - 场景内会有 10 个小动物自由移动、停留、说碎碎念。
  - 用户可以上下左右拖动浏览地图。
  - 直播聊天内容由“小动物碎碎念 + 用户宝宝照护记录生成的文案”组成，例如“12:08 宝宝喝了 120ml，好厉害”。
  - 直播 UI 包含顶部直播信息、在线/热度、右侧互动按钮、左下聊天流、底部输入/记录入口等，但明确是“模拟直播界面”。
- 技术方向：
  - 使用 `SpriteKit` 承载地图、小木屋、小动物、相机拖动、自由移动和点击命中。
  - 使用 SwiftUI `SpriteView` 嵌入 `SKScene`。
  - SwiftUI overlay 负责直播 UI、聊天列表、按钮、导航和未来业务弹窗。
  - 不采用纯 SwiftUI ScrollView 作为正式方案，避免后续动物动画、层级遮挡、路径移动和交互扩展变复杂。
- 本次实现约束：
  - 不碰当前 `HomeView` 的现有首页主体。
  - 只替换 `DailyMessageView` 空页面为“新首页实验页”。
  - 可以先用程序绘制/占位图形和 emoji 动物，不依赖最终美术资源；但结构按最终方案搭好。
  - 追求完整体验，不做临时 MVP 式堆叠。
