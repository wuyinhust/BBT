# BBBuddy UI Design System

> Version 1.0
> Based on the generated high-fidelity redesign and BBBuddy Brand Visual Handbook
> Platform: iOS (SwiftUI)
> Design Keywords: Playful · Soft · Futuristic · Tactile · Editorial · Premium

---

# 1. Design Philosophy

BBBuddy（BaByBuddy）是一款面向 0–3 岁婴幼儿家庭的记录与陪伴 App。

本设计系统融合以下三种视觉气质：

1. **宝宝产品的温柔与安全感**
2. **宝可梦般的角色活力**
3. **未来感消费级品牌设计**

整体视觉体验应当像：

* 一个高端母婴品牌
* 一个有灵魂的数字伙伴
* 一个柔软、会呼吸的记录工具

# 2. Core Visual DNA

## Keywords

* Soft
* Rounded
* Airy
* Playful
* Premium
* Dreamy
* Futuristic
* Minimal

## Design Principles

### 1. Extreme Rounded Corners

所有元素都采用高度圆角，营造“可触摸”的感觉。

### 2. Floating Cards

卡片悬浮于背景之上，配合轻阴影与边框。

### 3. Low-Saturation Purple

整体使用低饱和浅紫色作为品牌主色。

### 4. Character-Driven UI

Buddy 吉祥物自然融入界面。

### 5. Editorial Layout

留白充足，排版如高端杂志。

### 6. Emotional Micro-Interactions

通过渐变、模糊、发光增强情绪表达。
