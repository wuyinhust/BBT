# BabyBuddy RAG Knowledge Base

本目录存放 0-3 岁婴幼儿喂养知识库的结构化种子数据，面向 RAG 检索使用。

## 文件

- `knowledge_base.jsonl`: 主知识库，每行一条 JSON 记录。
- `sources.json`: 来源登记表，统一维护出处、URL、版权/使用备注。
- `schema.json`: 条目字段约束和枚举说明。

## 使用原则

1. 优先使用官方或专业组织来源：国家卫健委、中国营养学会、WHO/UNICEF、CDC、AAP。
2. 知识条目为中文转述和结构化摘要，不直接复制受版权保护书籍正文。
3. 每条记录必须保留 `source_ids`，回答用户时应引用来源而不是只给结论。
4. 风险等级为检索和产品提示用途，不能替代医生诊断。
5. 出现红旗症状、营养不良、贫血、严重过敏、窒息风险、脱水风险时，应提示及时就医。

## 建议检索过滤

常用过滤维度：

- `category`: 喂奶、辅食、饮食安全、营养监测、便便、睡眠、饮食行为、过敏。
- `age_min_months` / `age_max_months`: 按月龄召回。
- `risk_level`: `routine`、`caution`、`high`、`urgent`。
- `tags`: 用于同义词召回，如 `母乳`、`配方奶`、`辅食添加`、`贫血`。

## 版权说明

权威母婴书籍如果没有开放许可，只能在 `sources.json` 中登记为参考书目或在取得授权后再做文本入库。当前知识库不包含受版权保护书籍的长段正文。
