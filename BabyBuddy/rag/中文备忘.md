# BabyBuddy RAG 中文备忘

本目录用于保存 BabyBuddy 的育儿知识库种子数据，主要服务于 RAG 检索、回答 grounding、风险提示和后续人工扩库。

## 文件说明

- `knowledge_base.jsonl`：主知识库，每行一条 JSON 记录。
- `sources.json`：来源登记表，所有 `source_ids` 都应能在这里找到。
- `schema.json`：知识条目的字段约束、分类枚举和证据类型枚举。
- `README.md`：英文/通用说明。
- `COPYRIGHT_AND_SOURCING.md`：版权和来源使用原则。
- `中文备忘.md`：当前文件，给后续维护者看的中文备忘。

## 当前内容范围

知识库目前覆盖 0-3 岁宝宝，重点包括：

- 喂奶：母乳、配方奶、混合喂养、母乳储存、配方奶冲调。
- 辅食：约 6 月龄开始、富铁食物、新食物引入、质地过渡、家庭餐。
- 饮食安全：蜂蜜、添加糖、高盐、果汁、咖啡因、噎呛、高汞鱼、生奶。
- 营养监测：生长曲线、膳食多样性、贫血和血红蛋白筛查。
- 便便：颜色、便秘、腹泻、脱水和异常便色。
- 睡眠：1 岁内安全睡眠、仰卧睡、吐奶和反流场景。
- 哭闹：肠绞痛、安抚、安全暂停、3 月龄以下发热或异常哭闹。
- 气质：9 个气质维度，包括活动水平、规律性、接近/退缩、适应性、反应强度、情绪基调、坚持性、分心性、感官阈值。
- 发育里程碑：按 2、4、6、9、12、15、18、24、30、36 月龄整理。
- 社区话题：小红书和 Reddit 的育儿话题观察，用于理解用户问法和检索关键词。

## 来源分层

回答用户时要区分来源等级：

1. 官方指南和公共卫生页面：国家卫健委、中国营养学会、WHO、UNICEF、CDC、AAP/HealthyChildren 等。
2. 专业教育资料：ZERO TO THREE、IECMHC 等早期儿童发展机构资料。
3. 书籍参考：只登记书目信息或极短事实，不导入受版权保护正文。
4. 平台和社区观察：小红书、Reddit 只用于话题聚类、用户语言和检索同义词，不作为医学或育儿建议证据。

如果社区经验和权威指南冲突，回答必须以权威指南为准。

## 扩库规则

新增 `knowledge_base.jsonl` 条目时应遵守：

- 每行必须是完整、可解析的单行 JSON。
- `id` 要稳定且唯一，建议格式：`主题-月龄-序号`，例如 `solid-006-006`。
- `category` 必须来自 `schema.json` 的枚举。
- `source_ids` 至少 1 个，并且必须先登记到 `sources.json`。
- `content` 使用中文转述，不复制长段原文。
- `recommendations` 写可执行建议。
- `avoid_or_limit` 写禁忌、限制或常见误区。
- `red_flags` 写需要就医、急救或专业评估的信号。
- `risk_level` 只作为产品和检索提示，不是诊断。
- `answer_boundary` 要写清楚回答边界，尤其是医疗、过敏、发育迟缓、睡眠安全、窒息风险等场景。

## 风险等级参考

- `routine`：常规育儿信息，主要用于解释和日常建议。
- `caution`：需要提醒观察、结合个体情况或儿保评估。
- `high`：存在明显安全、营养、发育或照护风险，回答要更谨慎。
- `urgent`：可能需要立即就医、急救或联系医生。

## 社区话题使用边界

小红书和 Reddit 条目不要直接生成“照着做”的建议。它们的用途是：

- 识别用户常见问法，例如“睡眠倒退”“高需求宝宝”“辅食打卡”“BLW”“挑食”“如厕训练”。
- 做同义词召回，把口语问题映射到权威条目。
- 理解用户焦虑点和产品内容方向。

不能做的事：

- 不要复制平台用户帖子、评论或图片。
- 不要把热门经验当成通用建议。
- 不要用社区内容支持药物、补剂、偏方、危险睡姿、过早辅食、噎呛风险食物等建议。

## 常用校验命令

修改后可运行：

```bash
python3 - <<'PY'
import json
from pathlib import Path
base = Path('rag')
schema = json.loads((base / 'schema.json').read_text())
cat = set(schema['properties']['category']['enum'])
ev = set(schema['properties']['evidence_type']['enum'])
sources = json.loads((base / 'sources.json').read_text())
source_ids = {s['id'] for s in sources}
ids = set()
errors = []
for lineno, line in enumerate((base / 'knowledge_base.jsonl').read_text().splitlines(), 1):
    obj = json.loads(line)
    if obj['id'] in ids:
        errors.append(f'line {lineno}: duplicate id {obj["id"]}')
    ids.add(obj['id'])
    if obj.get('category') not in cat:
        errors.append(f'line {lineno}: bad category {obj.get("category")}')
    if obj.get('evidence_type') and obj.get('evidence_type') not in ev:
        errors.append(f'line {lineno}: bad evidence_type {obj.get("evidence_type")}')
    for sid in obj.get('source_ids', []):
        if sid not in source_ids:
            errors.append(f'line {lineno}: missing source {sid}')
print(f'entries={len(ids)} sources={len(source_ids)}')
if errors:
    print('\n'.join(errors))
    raise SystemExit(1)
print('validation=ok')
PY
```
