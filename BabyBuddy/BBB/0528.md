## 新增文件

### 1. `RhythmParameters.swift`（435 行）

**数据映射层**，将喂养/睡眠/尿布数据转为音频参数。

**四类输入信号：**

| 信号 | 来源 | → 影响的音频参数 |
|------|------|-----------------|
| 节律稳定度 | 喂养间隔方差、睡眠段长度方差、夜醒次数 | BPM、动态范围、段时长 |
| 日夜相位 | 最长睡眠段时刻、当前时刻 | 场景分类 → 预设选择 |
| 负荷指数 | 当天喂养/尿布频次、清醒时长 | 噪色配比偏移、旋律复杂度下调 |
| 年龄层 | `BabyProfileStore.shared.profile?.birthDate` | 0-3月 / 4-12月 / 1-3岁 → 不同预设 |

**核心类型：**
- `BabyAgeTier` — 年龄分层枚举（newborn / infant / toddler）
- `RhythmStability` — 稳定度评分（0 极不稳定 → 1 极稳定）
- `DayNightPhase` — 时段判定（夜间 19-6、午睡 11-15、其他）
- `CareLoad` — 照护负荷评分
- `RhythmInputs` — 四类信号合并，含周/日权重
- `PlaybackScenario` — 场景枚举（nightSleep / nap / fussy / calm）
- `RhythmPreset` — 12 套预设模板（3 年龄 × 4 场景）
- `RhythmParameters` — 最终音频参数（BPM、三段噪色配比、旋律复杂度、高频衰减、动态范围、段时长）
- `RhythmParameterMapper` — 无状态映射器，`derive()` + `extractInputs()`

**12 套预设：**

| 年龄层 | 场景 | 预设名 |
|--------|------|--------|
| 0-3 月 | 夜间安眠 | 子宫模拟（棕噪主导） |
| 0-3 月 | 平静陪伴 | 轻柔摇篮（粉噪+极简旋律） |
| 0-3 月 | 白天小睡 | 昼夜节律引导 |
| 0-3 月 | 安抚舒缓 | 深度安抚（高白噪掩蔽） |
| 4-12 月 | 夜间安眠 | 安稳入睡 |
| 4-12 月 | 安抚舒缓 | 夜醒安抚（短引入+高掩蔽） |
| 4-12 月 | 白天小睡 | 白天小睡（轻粉噪+旋律） |
| 4-12 月 | 安抚舒缓 | 出牙安抚 |
| 1-3 岁 | 夜间安眠 | 睡前故事配乐（更多旋律） |
| 1-3 岁 | 白天小睡 | 午睡时光 |
| 1-3 岁 | 夜间安眠 | 夜间安眠（棕噪+深沉旋律） |
| 1-3 岁 | 安抚舒缓 | 过度刺激日（极简白噪） |

**周/日双层权重：**
- 默认 `w_week = 0.7`，`w_day = 0.3`
- 当天稳定度 < 0.3 → 自动提升至 `w_week = 0.85`（保证听感稳定）
- 每天微调：BPM ±3、噪色配比、高频衰减、动态范围

### 2. `BabyAudioEngine.swift`（300 行）

**混音引擎**，替代旧的 `WeeklyRhythmPlayer`。

**噪声生成器（均以 session 种子初始化，保证同 session 内确定性）：**
- `WhiteNoiseGen` — 均匀随机 ±1，LCG PRNG 适合音频线程
- `PinkNoiseGen` — Voss-McCartney 算法（7 行累加器，-3dB/oct）
- `BrownNoiseGen` — 泄漏积分器（白噪累积 + 0.995 衰减）

**旋律生成：**
- `MelodyGen` — 五声音阶（C D E G A + 高八度），4.5 秒换一音
- 基频由 BPM 映射（BPM / 60 × 27.5 Hz）
- 含二次/三次谐波，复杂度由 `melodyComplexity` 控制
- 轻柔 tremolo 调制（0.55 Hz 正弦波 ±6%）

**三段式结构（90 秒缓冲区 @ 22,050 Hz 立体声）：**

| 段 | 时长 | 行为 |
|----|------|------|
| Intro | ~20-60s | 噪声从 70% ramp 到 100%，旋律渐入 |
| Settling | ~30-55s | 噪声从 100% ramp 到 80%，旋律稳定 |
| Sustain | ~30-55s | 保持稳定，循环播放 |

各段时长由 `RhythmParameters.introSec/settlingSec/sustainSec` 决定，稳定度低时引入段自动缩短。

**安全约束：**
- `SafetyConfig.maxAmplitude = 0.40` — 每次写入 buffer 前 hard clamp
- 高频衰减通过单极低通滤波器（600-11,000 Hz 可调）实现
- `@Published var errorMessage: String?` — AVAudioSession 启动失败时显示 alert
- `maxContinuousPlaySec` 到达后自动 `stop()`（夜间 60 分钟/白天 45 分钟）

**播放流程：**
```
play(with: params)
  → stop() 清理上一次
  → 用 Date().timeIntervalSince1970 生成 session seed
  → AVAudioSession.setCategory(.playback)
  → generateBuffer(params, seed) 生成 90s 缓冲区
  → playerNode.scheduleBuffer(loops: true)
  → startElapsedTimer(params) 监控连续播放
```

**首次播放前显示 4 页安全教育。**

| 页 | 主题 | 内容 |
